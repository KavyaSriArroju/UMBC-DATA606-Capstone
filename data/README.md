# Data Folder

This folder contains the datasets used in the PJM Electricity Load Forecasting project.

## Files Included

- `PJME_hourly.csv` – Original hourly electricity demand dataset
- `featured_data.csv` – Processed dataset after feature engineering

## Purpose

The datasets in this folder were used for:
- Exploratory Data Analysis (EDA)
- Feature Engineering
- Machine Learning Model Training
- Prediction and Evaluation

The processed dataset includes additional time-based and lag features created to improve prediction accuracy.
