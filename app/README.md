# Streamlit Dashboard

This folder contains the Streamlit application developed for electricity load forecasting visualization and analysis.

## Files

- `app.py` – Main Streamlit dashboard application
- `requirements.txt` – Required Python libraries

## Dashboard Features

- Upload processed dataset
- Visualize electricity demand trends
- Compare machine learning model performance
- Display actual vs predicted values
- Demand status monitoring

## How to Run

Open terminal in this folder and run:

```bash
streamlit run app.py
```
